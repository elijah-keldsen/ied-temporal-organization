# Public data

The release contains 114 pseudonymous cohort records, 20,406 evaluated full/split history-curve points, 39 anonymous repeat-recording pairs, model coordinates and bootstrap intervals, sleep-state summaries, and the relative-time Figure 1 excerpt.

Every participant-level table uses arbitrary `P###` labels. Response-unit names distinguish one-second detector-positive responses from merged onset events. See the repository `DATA_DICTIONARY.md` for the complete field-level specification.
