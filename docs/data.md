# Public data

The release contains 114 pseudonymous cohort records, 20,406 evaluated 1–90-second history-curve rows, 6,498 ratified 1–15-second history-curve rows, 39 anonymous repeat-recording pairs, model coordinates and bootstrap intervals, sleep-state summaries, and the relative-time Figure 1 excerpt.

Every participant-level table uses arbitrary `P###` labels. Response-unit names distinguish one-second detector-positive responses from merged onset events. The repository's `RESULTS_CHECKLIST.md` maps the reported values to these files, and `DATA_DICTIONARY.md` provides the complete field-level specification.
